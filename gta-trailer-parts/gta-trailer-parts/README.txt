GTA TRAILER PARTS - WORDPRESS THEME
===================================
INSTALL
1. WordPress admin > Appearance > Themes > Add New > Upload Theme > choose gta-trailer-parts.zip > Install > Activate.
2. On activation the theme creates: the 8 systems, 15 sample parts, a Home page (set as front page),
   a "Request a Quote" page (slug: quote), the main menu, and pretty permalinks.
3. Settings > Reading should show "A static page: Home". Appearance > Menus should show "GTA Primary" on Primary Menu.

EDIT CONTENT
- Header, phone, address, hours, announcement bar, trust strip, home text, Why GTA items:
  Appearance > Customize > "GTA: ..." panels.
- Logo: Appearance > Customize > Site Identity.
- Sections (the 8 systems): Parts > Systems (Sections). Edit name, description, tagline, number, tab colour, image.
- Parts: Parts > Add New. Title, short description (Excerpt), Featured Image, Part Details box
  (part number, spec line, badges, features, CVSA). Pick the System on the right. "Order" sorts the cards.
- Quote form emails go to the Email set in Customize > GTA: Top Bar & Contact. Install an SMTP plugin (e.g. WP Mail SMTP) so emails deliver reliably.

NOTES
- Starter section photos/logo were cropped from your screenshots and are low resolution. Replace them with your originals.
- Sample parts are placeholders; edit or delete them and add your real catalog.
